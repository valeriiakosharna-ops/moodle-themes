# Проверка Brand Boost для Moodle 5.2

Проверено 20 октября 2026 года в отдельном установленном Moodle с демонстрационным курсом.

| Компонент | Версия |
| --- | --- |
| Moodle | 5.2.4+ · Build 20261013 |
| Ветка / commit | `MOODLE_502_STABLE` · `31b4a0a6a678d785b6625f64b772bdb7a0446fe7` |
| PHP | 8.3.35 |
| PostgreSQL | 16 |
| Браузер | Chromium 153 через Playwright |
| Плагин | `theme_brandboost` · 2026102000 · 1.0.0 beta |

## Результаты

- Установка Moodle и регистрация дочерней темы — успешно.
- Компиляция SCSS для LTR и RTL командой `build_theme_css.php --themes=brandboost` — успешно.
- Синтаксис всех PHP-файлов плагина — без ошибок.
- **7 JavaScript-тестов** — прошли. Проверяются сохранённый выбор, системный режим,
  недоступное хранилище, принудительный режим сайта, синхронизация вкладок и готовый AMD-модуль.
- **15 серверных проверок** — прошли. Проверяются наследование Boost, палитра,
  валидация значений, ширина, штатные пресеты, загрузка собственного пресета,
  запасной пресет и приоритет пользовательского SCSS.
- **12 браузерных проверок** — прошли: вход, содержимое курса, карточки меню,
  светлый/тёмный/системный режимы, сохранение режима, закрытие/открытие и сохранение
  состояния панели курса, сворачивание разделов, панель блоков, мобильное меню,
  отсутствие горизонтального переполнения на 390 px и страница настроек.
- Необработанных ошибок JavaScript в браузерном сценарии — **0**.
- Axe WCAG 2 A/AA и WCAG 2.1 AA на странице демонстрационного курса: **0 найденных нарушений**
  в светлом и **0** в тёмном режиме. Это автоматическая проверка выбранной страницы,
  не сертификация доступности Moodle и всех его плагинов.
- Отдельная проверка сохранения через админку — прошла: запрет переключения скрывает селектор
  и применяет заданный тёмный режим; исходные настройки затем восстановлены через админку.

Скриншоты находятся в [docs/screenshots/brandboost/moodle-5.2](../screenshots/brandboost/moodle-5.2).
Инструкции запуска проверок — в [DEVELOPMENT.md](../DEVELOPMENT.md).

## Границы проверки

Тема предназначена для Moodle **5.2**. Moodle 4.0 и разрабатываемая `main` не заявлены совместимыми.
RTL-стили скомпилированы; визуальная проверка арабского/иврита не выполнялась.
Сторонние плагины, SCORM и внешние iframe, все роли и все учебные активности не проверялись.
Логотипы и favicon используют исходные API Moodle без переопределения, а не отдельное хранилище темы.
GitHub Actions **Check theme packages / packages** завершился успешно:
[результат CI](https://github.com/valeriiakosharna-ops/moodle-themes/actions/runs/39482155606).
CI проверяет сборку, JavaScript-тесты, PHP-синтаксис и соответствие готового ZIP исходникам;
проверки запущенного Moodle, описанные выше, выполнялись отдельно.

Для визуального сравнения изучена Magnific **9.8.1 / 2026101400**:
`8d82d8050e5a5cae0247b535524b842316b241fc`.
Её исходники и медиа в архив не включены.
