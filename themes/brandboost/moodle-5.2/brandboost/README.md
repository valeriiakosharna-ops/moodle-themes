# Brand Boost · Moodle 5.2

Дочерняя тема Boost с брендовой палитрой, светлым, тёмным и системным режимами.
Устанавливается как отдельный плагин `theme_brandboost`; изменять Moodle или Boost не нужно.

## Установка

1. Сделайте обычную резервную копию сайта и проверьте тему на тестовом Moodle **5.2**.
2. Загрузите `theme_brandboost_moodle52_2026102000.zip` в **Администрирование → Плагины → Установка плагинов**.
   Альтернатива: распакуйте папку `brandboost` в `<moodle>/public/theme/brandboost`.
   Это каталог для новой структуры Moodle 5.2 с `public/`; web-сервер должен читать файлы.
3. Откройте **Администрирование → Уведомления**, завершите установку.
4. Выберите **Brand Boost** в **Внешний вид → Темы → Выбор темы**.
5. Откройте **Внешний вид → Темы → Brand Boost** и сохраните параметры.

На сервере не нужны Node.js, npm или сборка JavaScript: готовый AMD-модуль включён в архив.
Boost должен оставаться установленным. Для CLI используйте корень Moodle, содержащий `config.php`:

```sh
php admin/cli/upgrade.php --non-interactive
php admin/cli/purge_caches.php
php admin/cli/build_theme_css.php --themes=brandboost
```

## Что настраивается

- Все восемь цветов бренда: `#00A6EB`, `#E60036`, `#81D0F4`, `#EF958C`, `#2A668E`, `#937C8A`, `#302A40`, `#951B3C`.
- Режим по умолчанию: светлый, тёмный, системный; разрешение переключать режим.
- Ширина содержимого: 1280 px, 1520 px или вся доступная ширина.
- Пресеты Boost `default.scss`, `plain.scss` и загрузка собственных SCSS-пресетов.
- Фон сайта, фон страницы входа, SCSS до и после основной компиляции.
- Исключаемые из добавления блоки — как в Boost.

**Логотип, компактный логотип и favicon:** штатная страница **Внешний вид → Логотипы**.
Сохраняются языковое меню, дополнительные пункты меню, уведомления, сообщения, поиск,
редактирование курса и блоков, настройки доступности и формы аутентификации Moodle.
Права, доступные действия и содержимое меню определяет Moodle.

Настройки Brand Boost и Boost независимы. Глобальные логотипы подхватываются сразу;
пользовательские SCSS, пресеты и фоны из Boost при переходе нужно перенести в настройки Brand Boost.
Брендовый слой накладывается поверх выбранного пресета. Поле дополнительного SCSS выполняется последним.

## Навигация

Разделы штатного индекса курса оформлены отдельными карточками; активный пункт выделен,
разделы сворачиваются. Используются исходные drawer, кнопки закрытия и открытия, клавиатурная
навигация и сохранение состояния Boost. Тема не фиксирует панель открытой.
На остальных страницах остаётся штатная навигация Boost, на мобильных — его выдвижное меню.
Скрытые преподавателем элементы и перетаскивание в режиме редактирования работают через Moodle.

## Светлый и тёмный режим

Переключатель находится в верхнем меню. Выбор сохраняется **в текущем браузере для данного сайта**,
не синхронизируется через профиль и не передаётся на сторонний сервис.
Системный режим реагирует на изменение темы устройства без перезагрузки.
Если администратор запрещает переключение, сохранённый выбор игнорируется.
На странице входа применяется ранее выбранный режим или значение сайта; вход и MFA остаются штатными.

Тёмный режим покрывает оболочку Moodle, навигацию, карточки, таблицы, формы и диалоги.
Сторонние плагины, SCORM/iframe, содержимое курсов с заданными вручную цветами и редакторы
в отдельных iframe могут требовать собственного оформления. Изображения и учебный контент не инвертируются.
Пользовательские цвета и SCSS нужно проверять на контрастность. В исходной палитре яркий голубой
сочетается с контрастным тёмным текстом кнопок, а ссылки используют глубокий синий.

## Обновления и будущая версия для Moodle 4.0

Эта сборка предназначена **только для Moodle 5.2**. Moodle `main` — разрабатываемая версия,
она не является целевой платформой этой сборки. `version.php` отмечает совместимость с 5.2.

Основа для последующего переноса:

- палитра и проверка значений — `lib.php`;
- семантические CSS-переменные `--bb-*` и оформление — `scss/brand.scss`;
- подключение к API Moodle 5.2 — `config.php`, `settings.php`, `classes/output/core_renderer.php`;
- независимая логика режимов — `javascript/appearance-init.js` и `amd/src/appearance.js`;
- единственное переопределение шаблона Boost — декоративная панель входа `templates/core/login_panel.mustache`.

Для 4.0 потребуется отдельный адаптер/ветка под Bootstrap 4, его структуру плагинов,
формы и навигацию. Снижать `$plugin->requires` для установки этой сборки на 4.0 нельзя:
это не обеспечивает совместимость. Палитру и логику режимов можно использовать повторно.
